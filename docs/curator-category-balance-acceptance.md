# Acceptance — autonomous curator category balance

- [ ] Every one of the 10 public categories is counted independently.
- [ ] Category target is exactly 2 active published products.
- [ ] A category below 2 remains eligible on recovery cycles even if it published less than 24h ago.
- [ ] A category already at 2 does not gain a third persistent visible product during bootstrap.
- [ ] After all categories reach 2, publication cadence returns to >=24h per category.
- [ ] A daily new product replaces the oldest visible product in its category.
- [ ] Existing image/editorial/similarity/affiliate/pipeline gates are unchanged.
- [ ] Catalog sync validates the final balanced visibility state.
- [ ] Run metadata records per-category counts and deficits.
- [ ] Telegram balance summary reports category coverage.
